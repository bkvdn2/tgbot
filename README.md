# Бот анонимных сообщений

Пользователь пишет боту → тебе (админу) приходит сообщение, а следующим сообщением — карточка отправителя (имя, @юзернейм, ID) с кнопками «Заблокировать» / «Разблокировать» / «В канал».
Чтобы ответить отправителю — свайпни (reply) на его сообщение и напиши ответ: он придёт пользователю от лица бота.

Для получателей и подписчиков канала сообщения анонимны. В приветствии бот сообщает пользователям, что админ видит отправителя (для модерации).

## Запуск в Termux

1. Установи Termux **из F-Droid** (версия из Google Play устарела и не обновляется).
2. Обнови пакеты и поставь Python и git:
   ```sh
   pkg update && pkg upgrade -y
   pkg install -y python git
   ```
3. Скачай бота:
   ```sh
   git clone https://github.com/bkvdn2/tgbot.git
   cd tgbot
   ```
4. Поставь зависимости:
   ```sh
   pip install -r requirements.txt
   ```
5. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
   Свой ID узнай у [@userinfobot](https://t.me/userinfobot).
6. Создай файл настроек:
   ```sh
   cp .env.example .env
   nano .env
   ```
   Впиши `BOT_TOKEN` и `ADMIN_ID`. Сохранить в nano: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.
   (`Ctrl` в Termux — кнопка на дополнительной панели над клавиатурой.)
7. Запусти:
   ```sh
   python bot.py
   ```
   Остановить — `Ctrl+C`.

### Чтобы бот не умирал при сворачивании Termux

```sh
termux-wake-lock          # не даёт Android усыпить Termux
pkg install -y tmux
tmux new -s bot           # открыть сессию
python bot.py
```
Отсоединиться, оставив бота работать: `Ctrl+B`, затем `D`. Вернуться: `tmux attach -t bot`.
Ещё стоит отключить для Termux оптимизацию батареи в настройках Android.

### Обновить бота
```sh
cd ~/tgbot && git pull
```

## Пересылка в канал (заготовка)

1. Добавь бота в канал администратором с правом публикации.
2. В `.env` укажи `CHANNEL_ID` (`@username_канала` или `-100...` для приватного).
3. Теперь у каждого сообщения появится кнопка «📢 В канал» — ручная публикация.
4. Для автопубликации всех сообщений поставь `CHANNEL_ENABLED=1`.

В канал сообщение копируется без указания автора. Логика — функция `post_to_channel` в `bot.py`.
